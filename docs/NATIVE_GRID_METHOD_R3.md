## 1. Scientific Background & Rationale

The CGMacros v1.0.0 dataset publishes continuous glucose measurements on a uniform 1-minute temporal grid. However, standard commercial continuous glucose monitors (CGMs) do not record at 1-minute intervals:
- **FreeStyle Libre Pro (Abbott):** Records interstitial glucose every 15 minutes.
- **Dexcom G6 Pro (Dexcom):** Records interstitial glucose every 5 minutes.

The dataset documentation states that 1-minute values were generated by linear interpolation between raw sensor readings. This introduces critical implications for digital twin modeling:
1. **Information Horizon:** 1-minute values between native samples are deterministic interpolations, not independent physiological observations.
2. **Causal Leakage Risk:** A machine learning model predicting $y_{t+1}$ from $y_t$ on a linearly interpolated grid would exploit future native sample information interpolated backward into $y_t$, creating severe data leakage.
3. **Sensor Concordance:** Comparing sensors on the 1-minute grid evaluates interpolated traces rather than raw hardware concordance.

Stage 1B-R3 implements a mathematically rigorous, detector-blind native-grid inference engine that recovers the true underlying sampling lattices directly from the 1-minute data without relying on metadata assumptions.

## 2. Mathematical Formulation & Time Semantics (T1–T7)

### 2.1 Explicit Contiguous Runs
Row index is never treated as a temporal coordinate. Time series are decomposed into contiguous runs of valid sensor observations:
$$\mathcal{R} = \{ (t_{\text{start}}, t_{\text{end}}) \mid \forall k \in [t_{\text{start}}, t_{\text{end}} - 1], \, t_{k+1} - t_k = 60\text{ s} \text{ and } y_k \in \mathbb{R} \}$$

### 2.2 Run-Bounded Second-Difference Curvature
Under linear interpolation between native sample points at period $P$:
$$y_t = y_{t_a} + \frac{t - t_a}{t_b - t_a} (y_{t_b} - y_{t_a}), \quad t \in (t_a, t_b)$$
The first difference $\Delta y_t = y_{t+1} - y_t$ is strictly constant on $t \in [t_a, t_b - 1]$. Consequently, the absolute second difference:
$$d_2(t) = |y_{t+1} - 2y_t + y_{t-1}| = |\Delta y_t - \Delta y_{t-1}|$$
is identically zero at all interpolated interior points, and non-zero (exhibiting curvature "bends") exclusively at native sample vertices $t = t_b$.

Second differences are evaluated strictly on interior run points:
$$\forall t \text{ such that } \{t-1, t, t+1\} \subset r, \quad r \in \mathcal{R}$$
This completely eliminates false boundary bends.

### 2.3 Elapsed-Time Phase Selection
Let $t_0$ be the series reference timestamp. The elapsed minute coordinate is:
$$m(t) = \left\lfloor \frac{t - t_0}{60\text{ s}} \right\rceil$$
For candidate period $P \in \{5, 15\}$ and phase $\phi \in \{0, \dots, P-1\}$, the candidate native lattice is:
$$\mathcal{L}_{P, \phi} = \{ t \mid m(t) \equiv \phi \pmod P \}$$
The lattice hit rate is computed across all detected bends $\mathcal{B}$:
$$\text{HitRate}(P, \phi) = \frac{1}{|\mathcal{B}|} \sum_{b \in \mathcal{B}} \mathbb{I}(m(b) \equiv \phi \pmod P)$$
The optimal phase is $\phi^*_P = \arg\max_\phi \text{HitRate}(P, \phi)$.

### 2.4 Nested Lattice Disambiguation & The Nested Lattice Mathematical Principle
Because 15 is an integer multiple of 5, any true 15-minute lattice $\mathcal{L}_{15, \phi}$ is a subset of the 5-minute lattice $\mathcal{L}_{5, \phi \pmod 5}$. A naive hit rate test will register high hits for both $P=5$ and $P=15$.

**The Fundamental Nested Lattice Mathematical Principle:**
A denser linear grid ($P=5$) always reconstructs a coarser piecewise-linear grid ($P=15$) with zero residual, because any affine segment on $[t, t+15]$ is trivially also piecewise-linear on $[t, t+5]$, $[t+5, t+10]$, and $[t+10, t+15]$ with identical slope. Consequently, a near-zero reconstruction residual on a denser nested grid does **not** prove that $P=5$ is the true native sampling lattice. The only genuine distinguishing evidence is the presence of intermediate curvature bends ($d_2(t) > 0$ at $t \not\equiv \phi^*_{15} \pmod{15}$) and a low distinction ratio $\mathcal{R}_{\text{inter}} < 3.0$.

To decisively separate 15-minute from 5-minute lattices:
1. **Intermediate 5-minute Bend Ratio:** Under true 15-minute linear interpolation, bends at intermediate 5-minute phases $\phi_{\text{inter}} \in \{ (\phi^*_{15} + 5) \pmod{15}, (\phi^*_{15} + 10) \pmod{15} \}$ must be strictly zero. The distinction ratio is:
   $$\mathcal{R}_{\text{inter}} = \frac{\text{Hits}(\phi^*_{15}) + 1}{\sum_{\phi \in \phi_{\text{inter}}} \text{Hits}(\phi) + 1}$$
   If $\mathcal{R}_{\text{inter}} \ge 3.0$ and intermediate bends $< 5\%$, the 15-minute lattice is confirmed.
2. **Run-Bounded Linear Reconstruction Residual:** Within each contiguous run containing $\ge 2$ native points, the 1-minute trace is reconstructed via linear interpolation between the candidate native points:
   $$\hat{y}_t = \text{Interp}(t; \{m \in \mathcal{L}_{P, \phi^*}\}, \{y_m\}), \quad t \in [m_{\text{first}}, m_{\text{last}}]$$
   The mean absolute reconstruction residual:
   $$\bar{\epsilon}_{\text{recon}} = \frac{1}{|\mathcal{T}_{\text{eval}}|} \sum_{t \in \mathcal{T}_{\text{eval}}} |y_t - \hat{y}_t|$$
   must satisfy $\bar{\epsilon}_{\text{recon}} \le 0.25\text{ mg/dL}$ for high confidence.
