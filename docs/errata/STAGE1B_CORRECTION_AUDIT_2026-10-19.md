| **ISSUE-1** | Native Grid & Pairing | Timestamp-blind index modulo (`arange(n) % 15 == phase`) breaks when an absent-timestamp gap occurs mid-series. Second differences across gap boundaries create false bends. | **CONFIRMED DEFECT** | `src/dtwin/analysis/native_grid.py:infer_native_grid_series` (L126-215)<br>`src/dtwin/analysis/run_stage1b.py` (L134-142) | Code used `np.arange(n_pts)` without verifying timestamp deltas. | **ISSUE-2** | Horizons & Forecast Difficulty | `dropna()` followed by positional slicing (`s[30:] - s[:-30]`) bridges across missing intervals and absent timestamps. | **CONFIRMED DEFECT** | `src/dtwin/analysis/run_stage1b.py` (L145-165)<br>`src/dtwin/analysis/tasks.py:evaluate_forecast_difficulty` (L38-55) | Code ran `clean = series[~np.isnan(series)]` then `clean[h:] - clean[:-h]`. | **ISSUE-6** | Lag Sign Convention & Attribution | Cross-correlation lag sign convention was not synthetically verified. | **ISSUE-7** | Benchmark Generator Independence | Synthetic benchmark generator and detector resided in the same module (`native_grid.py`) and shared assumptions. | **CONFIRMED DEFECT** | `src/dtwin/analysis/native_grid.py:generate_synthetic_trace` (L60-125) | Generator and detector shared internal structures. | **ISSUE-8** | Censored Values | Sensor hardware limit values (floor/ceiling) were not analyzed separately. | **CONFIRMED DEFECT** | `src/dtwin/analysis/run_stage1b.py` (L100-140) | Code did not quantify sensor saturation limits ($40$ and $400\text{ mg/dL}$) or run censored vs non-censored sensitivity analyses. | Quantify floor/ceiling occurrences per device. Run agreement analysis with and without censored values. |
| **ISSUE-9** | Self-Certifying Language | Reports used self-certifying language ("PASSED", "CERTIFIED FOR STAGE 2") rather than revision-pending language. | **CONFIRMED DEFECT** | `docs/STAGE1B_REPORT.md`<br>`docs/reports/stage1b_report.md` | Headers and conclusions stated "PASSED & CERTIFIED FOR STAGE 2". | Replace all self-certifying status labels with "CORRECTED REVISION — PENDING INDEPENDENT REVIEW". |
